# 普通混凝土配合比设计系统

依据 **JGJ55-2011《普通混凝土配合比设计规程》** 的纯前端配合比设计工具，开箱即用，无需后端。

原项目为 Streamlit 版本（`app.py` + `concrete_core.py`），本仓库将其重写为**零依赖静态站点**，可直接部署在 GitHub Pages。

## 功能

| 模块 | 说明 |
|---|---|
| **配合比计算** | 配制强度 → 保罗米公式反推 W/B → 耐久性复核 → 查表定用水量/砂率 → 重量法配骨料 → 施工配合比（含水率修正） |
| **成本 – 碳排放对比** | 纯水泥 / 掺 FA 25% / 掺 SL 25% / 双掺各 15% 四方案双轴对比 |
| **合成级配曲线** | 14 档标准筛，砂率可拖动实时重算，含细度模数与断档诊断 |
| **参数可行域热力图** | W/B × 砂率 网格逐点校核 6 条规范约束，标出当前设计点 |
| **敏感性龙卷风图** | 6 个关键参数各 ±10% 扰动，量化对 W/B 与成本的影响 |
| **Monte Carlo 风险分析** | 1 万次采样给出强度分布与达标概率；二分搜索反算"最经济可行 W/B" |

## 使用

直接打开 `index.html` 即可，或本地起一个静态服务：

```bash
python -m http.server 8000
# 访问 http://localhost:8000
```

## 技术说明

- `js/core.js` —— 计算内核，收录全部规范查表数据（σ、γc、用水量、砂率、耐久性限制、保罗米系数），提供二维线性插值、约束网格评估、伪随机蒙特卡洛等
- `js/charts.js` —— 自研轻量 SVG 图表引擎（折线/柱线双轴/热力图/龙卷风/直方图/横条），无 CDN 依赖
- `js/app.js` —— 界面绑定与渲染调度

## 相对原 Streamlit 版本的修正

1. **细度模数公式**：原 `FM = [(ΣA) − 5·A0.075] / (100 − A0.075)` 混用了"累计筛余"与"分计筛余"两种口径，仅在默认参数下巧合得到合理值，换用真实砂样即失效。已改为 `FM = (Σ累计筛余[4.75…0.15]) / 100`，对 II 区中砂、粗砂、特细砂等样本均给出合理分类。
2. **默认级配数据**：原砂级配在 4.75 mm 处仅通过 2%，导致砂石曲线交界处出现断崖式假断档。已替换为 II 区中砂 + 5–20 mm 连续级配碎石的典型曲线。
3. **未定义筛孔的外推**：原逻辑将未定义筛孔一律视为 100% 通过，导致 26.5 mm 以上凭空出现断档。改为按最粗已定义筛孔外推。
4. 修复成本对比表中 0% 差值被误标为"持平"的显示问题。
